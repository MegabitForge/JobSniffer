# Job Sniffer

Job Sniffer is a Windows desktop application that will collect job offers and evaluate how well they match a candidate's resume using a LLM.

## Requirements

- Python 3.14
- [uv](https://docs.astral.sh/uv/)

## Run

```powershell
uv sync
uv run job-sniffer
```
